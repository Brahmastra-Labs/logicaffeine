# scripts

The repository's tooling. The top level holds what people run and the FPGA and silicon tooling (board hosts, hardening, the signoff and power recorders); every other script lives in the folder for its area. Each script's header says what it does and how to call it.

## Entry points

| Script | What it does |
|---|---|
| `run-all-tests-fast.sh` | The full suite on cargo-nextest: every crate, the Z3 `verification` tests, the ignored heavies and doctests. The on-demand classes below are left to their own runners. |
| `run-all-tests.sh` | The same surface on `cargo test`, one binary at a time: the slow ground-truth baseline. |
| `compare-test-runs.sh` | Proves two run logs executed the same tests. |
| `test-count.sh` | The workspace test count, computed as the CI badge computes it. |
| `run-research-tests.sh` | The SAT/coNP research probes, run on purpose. |
| `run-silicon-tests.sh` | The gate-level silicon simulations and the D5005 card co-simulations, run on purpose. |
| `run-kernel-pending-tests.sh` | The kernel specs for an importer capability not built yet, run on purpose: green while each fails with its recorded gap, red the day one passes. |
| `run-opt-audit-tests.sh` | The exhaustive optimization-graph completeness audit, run on purpose. |
| `run-qemu-corpus-tests.sh` | The RISC-V benchmark-corpus differentials under qemu, run on purpose. |
| `run-model-bars-tests.sh` | The decode engine's real-checkpoint accuracy bars against llama.cpp's runs, run on purpose. |
| `run-arena-mathlib-tests.sh` | The Lean Kernel Arena mathlib cases, run on purpose. |
| `run-handed-reds-tests.sh` | The RED tests handed out with the fusion book's tickets, run on purpose: green while each suite is red, red the day one passes behind its gate. |
| `run-opt-in-feature-tests.sh` | The suites behind the features the baseline leaves off (`nbe`, `shadow`, `io-uring`, `capnproto`, `ffi-link-tests`, `narrow-value`), run on purpose. |
| `bump-version.sh` | Moves the lockstep version to every surface that writes it. |
| `generate-docs.sh` | The handbook: every guide and crate README as one book in `target/docs/LOGOS_DOCUMENTATION.md` (`--with-source` appends the core source). |
| `generate-roadmap.sh` | The web roadmap's release history, from `CHANGELOG.md`. |
| `check-packaging.sh` | Builds every published crate from the tarball crates.io would receive. |
| `check-binary-sizes.sh` | Holds every shipped binary to its budget in `.config/size-budgets.toml`. |
| `tt-sim.sh` | Runs a tt-metal program under ttsim, Tenstorrent's full-system simulator. |
| `tt-matmul-measure.sh` | The only path from a ttsim run to a row of `benchmarks/silicon/tenstorrent_gemm.json`. |
| `tt-gemm-ledger.py` | The only writer of that ledger. Its rows record these three tools by path, so they stay here. |
| `decode-host.py` | Runs the tiny transformer's decode image (`benchmarks/silicon/decode_images.json`) on Board A or B: the golden trace over the board's byte channel, every token and step held to the trace and the twin, and the chip's measured decode time, with the board's power when a meter gives it. |
| `split-host.py` | Runs the decode step split over both boards (`benchmarks/silicon/decode_split_images.json`): each chip's image on its board, the tensors that cross relayed between them by the host, every halt, token and count of cycles held to the record, and the wall time each step took. |
| `logos-terminal.py` | The Fabric Terminal on Board B: an editor and program library on the board's VGA screen, typed on its USB keyboard or the laptop's, each program compiled and run on the fabric engine with the engine's activity drawn live; `--check` runs the whole library unattended against the VM. |

## Paths in older records

Ledgers, logs and comments written before 0.11.0 name scripts at the top of `scripts/`. Each file kept its name, and no two scripts share one (`repo_shape_lock` holds that), so the name finds it: `find scripts -name <file>`.

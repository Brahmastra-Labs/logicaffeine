# Changelog

All notable changes to this crate will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- `lia::fourier_motzkin_unsat_within(constraints, budget) -> Option<bool>`: Fourier–Motzkin elimination that gives up
  (`None`) once a step would leave more than `budget` constraints. `fourier_motzkin_unsat` is the unbounded case and
  decides as before.
- `dag::arena::run`: the Lean Kernel Arena's protocol over the `dag` core (one lean4export stream, a check by an
  engine, exit 0/1/2, the reason on stderr), the one function the Arena entry's run line, `largo lean check` and the new
  `logos-kernel` binary (`src/bin/logos-kernel.rs`, the value engine, or both under `--dual`) run; `dag::arena::verdict`
  returns that verdict for a caller that goes on, and `interface::lean::pipeline`'s independent recheck asks it of the
  whole export, failing the stage (`RecheckRefused`) when the core refuses what the `Term` kernel accepted. The README's
  Acknowledgements credit the work the core builds on.

### Changed

- **The value engine checks Mathlib in 29% fewer instructions.** `logos_kernel --check sem`, built as the Lean Kernel Arena entry builds it, checks the Arena's whole Mathlib export in 409.15 G instructions, from 577.15 G (its first 2 GB in 118.60 G, from 163.86 G); the heavy `perf` cases fall by more than a quarter too (`magma-list-pair-n21` 25.92 → 18.98 G, `magma-list-deep-n36` 27.54 → 20.56 G), every verdict unchanged.
  - The Arena entries train their profile on the Arena's `init` and `init-prelude`, `init-prelude` merged at sixty times its weight, so that the declarations a small test spends its time on stay as hot as Mathlib's checking; `snapshot.sh` trains alike.
  - The new `unchecked-access` feature reads the `dag` core's stores — expression entries, value records, environments, spines, frames and hash-table slots — through `dag::slot`, which drops the bounds check: every id the core reads with was handed out by the store it reads, and stores only grow within the scope their ids live in. The Arena entries, `snapshot.sh` and `instr.sh` build with it; every other build and every test keep the checks, and debug builds assert the bound either way. `arena_entry_lock` holds the entries' and the measured snapshot's builds to the feature.
  - A variable's value and type are read in place; the value or type remembered for anything else is found in the caller's frame (`Sem::eval`, `Sem::infer`, `whnf`, `whnf_core`, `type_of`, `is_proof`, `is_def_eq`), and computing one is an outlined call. A call that only prunes an environment and probes the caches returns to its caller before the computation recurses, the probes are forced inline only in optimized builds, and refusals are formatted out of line, so an unoptimized build's recursion stays within a thread's default stack.
  - A neutral's arguments lie contiguously in the arena and a neutral is interned by its head and argument list: applying a head to all its arguments is one probe, with no intermediate partial applications (`Arena::neutral_apply`), and `Arena::spine`/`spine_arg`/`arg` read arguments in place.
  - An application's spine is read into a stack buffer (`Store::short_app_args`), an inference miss reads its expression's entry once, and an argument whose type is already its domain skips the `eagerReduce` test.
  - An environment remembers its last extension (`EnvNode::xval`/`xres`, forgotten with the session), so extending it by the same value again needs no table probe; a neutral's openness is computed only when it is created.
  - An environment remembers its two latest prunings (`EnvNode::pmask`/`pres`), which replace the pruning cache; a pruning picks its values straight into the frame store's tail, in one walk, and keeps them only when no frame holds them yet (`Arena::prune`). A neutral built from a closure's arguments takes them from a stack buffer.
  - A universe substitution is shared rather than copied when it is applied, and two level lists are compared in place (`Levels::subst`, `Levels::equiv_lists`).
  - The absent-parameter analysis reads a definition's loose variables from the masks the store keeps, walking the term only when an index of 64 or more makes the mask inexact (`relevance::absent_mask`), and reserving room in the persistent expression table rehashes once, straight to the capacity that holds it (`Store::reserve_persistent`).

## [0.11.0] - 2026-11-02

### Added

- `prelude::axiom_dependencies_given`: the axiom closure of a term where a callback answers for constants whose closure is already taken, and the walk stops there. The Lean importer's declaration audit passes the axiom sets it recorded, so a declaration's audit walks its own terms and what is not yet audited, not its whole closure again; every audited set is the one the full walk finds.
- **Every certified quotient computes in the core.** `Theory::Logos` admits the quotient a kernel installs for content imported from Lean (`kernel.quot.*`) beside the standard library's, each by its own four names (`dag::wellknown::QuotNames`, the core environment's `quotients`) and against the canonical equality its lift is stated with (`quotient::Certificate::equality`, checked as Lean's `init_quot` checks `Eq`); a lift or induction steps on its own quotient's constructor only. Lean's `funext`, proven through the quotient, is admitted by both kernels. `Theory::Lean` keeps its one quotient.
- **The core's mirror on a thread of its own, and a shadow that compares what a door registered.** `dag::mirror::sync` and `with` run on a per-thread core thread with the core's stack, so an admission that recurses as deep as its declaration never meets a caller's stack, and the mirror never moves between threads. In shadow mode a door's entry fixes the log's head and only the names logged past it are compared; a refusal that follows from one the core made before (`Synced::downstream`) is not reported again, so a declaration registered unchecked or re-decided in a replay is no door's verdict; the shadow stands down in a context with local bindings, whose declarations may be open in them. `Theory::Logos` decides structure η as the `Term` kernel does: a structure's value is its constructor applied to its match-written projections.
- **Observational equality (`observational`).** `observational::register` adds `Obs.{u} A a b : SProp` with `Obs_refl`, `Obs_transp` (its elimination into `SProp`) and `Obs_cast` (a value carried along an equality of types), the `SProp` connectives `STrue`, `SFalse`, `SAnd`, `SSigma`, `SBox` with their projections, and `EqvGen`, the equivalence closure of a relation. `Obs` computes on the type it compares at: pointwise at a function type (function extensionality by conversion), logical equivalence at `SProp` and `Prop` (propositional extensionality), by formers at a universe, by constructors at an inductive family, by the equivalence closure at a quotient (so `Quot_sound` is a theorem). `Obs_cast` computes along universes, function types, parameterized families and quotients, so a closed numeral carried by `Obs_cast` is a numeral. A rule never compares two proofs by their constructors, never a proposition seen as a type by its former, and a family's arguments only when its universe can store them. The constants are certified as the quotient's are: the rules fire for the certificate's names alone, displacing a name it rests on revokes it (logged by the admission log, part of the order cache's key), and an uncertified constant of the same spelling is an assumption. Both kernels and the `dag` core (`dag::logos_obs`) compute them.
- **Shadow mode (`shadow` feature).** Every checked door's verdict is decided again by the context's mirrored core (`dag::mirror`): an admission by a sync after the door (a name the door left pending counts as a refusal), a refusal of the theory by judging the refused candidate in the unchanged context (`dag::logos_env::judge`, `check_without_admitting`); a door's own policy (a name already taken) is no verdict of the theory. A disagreement panics with both verdicts; the shadow stands down while the standard library registers. `scripts/run-opt-in-feature-tests.sh` runs the decision's controls with it.
- **LOGOS's calculus runs on the `dag` core (`Theory::Logos`).** The hash-consed core that checks Lean exports also decides LOGOS's own theory: `dag::logos` lowers and lifts `Term`s, open terms included; `dag::logos_env::{admit, replay, Declaration}` admits inductive blocks (parameters uniform, every constructor returning its family at the parameters with indices free of the block, fields at most at the family's level, recursive and reflexive shapes recorded), definitions, axioms, and the quotient primitives as one certified item; and `dag::logos_tc` holds the rules LOGOS has beside Lean's: indexed `match` with motive validation and coverage over the constructors the indices allow, `fix` and mutual `fix` under the guard and checked against the type their position expects, the K-like rule, cumulative inductives (Timany–Sozeau irrelevant-level masks), the `Int` literal bridge, and the elimination restrictions (`SProp` only into `SProp`; a family that may be `Prop` into a larger sort only as a subsingleton or at most at its own level). It admits every declaration of the standard library and refuses each paradox of `kernel_paradox_corpus` by the rule the `Term` kernel refuses it by. `Theory::Lean` is unchanged in what it decides and in its cost: on the Arena's engine (`--check sem`, one box, before and after) init 26.07 G → 25.72 G, std 44.21 G → 43.59 G and Mathlib 586.41 G → 577.97 G, every Arena verdict the same (logs/arena-crown/stage-d/ab/)
- **Tactics over the kernel's own goals (`tactics`).** `GoalState` proves a statement as Lean's tactic framework does: each goal is a metavariable with its hypotheses and target, a tactic assigns the focused one a term that may hold new goals, and `qed` hands the closed proof term to the kernel, which checks it against the statement, so no tactic is trusted. The tactics are `intro`, `exact`, `apply`, `assumption`, `exfalso`, `constructor`, `left`, `right`, `exists`, `have`, `rfl`, `change`, `rewrite` (either direction, occurrences under binders, capture avoided), `induction` (any family with a derived recursor, indices generalized, dependent hypotheses reverted and reintroduced) and `cases` (an indexed `match` that owes no case for a constructor the indices exclude). A step that does not apply leaves the state as it found it. Goals and tactic messages are spelled by the vernacular printer (`⊢ Eq Nat Zero Zero`). The vernacular takes a script as a theorem's proof, `Theorem t : P := by intro x; exact h.` (`Command::TheoremBy`, `InterfaceError::Tactic` naming the step and its goal), printed back as written.
- **The core's mirror of a context (`dag::mirror`).** A `Context` keeps an admission log, a persistent list of every change to the registries a declaration lands in: `Context::record` is the one door into them, and `displace`, the standard quotient's certification (`Context::certify_prelude_quotient`) and its revocation log what they remove or certify. `dag::mirror::sync` brings a thread's `Kernel::logos` to a context: the same log head is current; a log that reaches the mirror's head admits only the new declarations, in dependency order; a sibling of the standard library restarts from a per-thread snapshot of its core (a `Kernel` is a plain value and clones); anything else, and a change to something the mirror holds, replays the context. Every route ends where `logos_env::replay` ends, constant by constant and verdict by verdict. The replay and the mirror read a name by one precedence (`Context::registration`), and a literal names its carrier among a declaration's dependencies, so a declaration holding an `Int` literal is admitted after `Int`.
- **More tactics, each building its proof term.** `refine t` makes every hole it leaves a goal in the scope of the binders around it (the elaborator records each hole's type and context, `MetaCtx`'s hole declarations, as Lean's `MetavarDecl`); `subst h` replaces a hypothesis by the side of an equation that determines it; `injection h as [e …]` states the equations of a constructor's fields, each a transport into a predicate that matches on the value (the construction Lean's `noConfusion` packages), and closes a goal whose equation relates two constructors; `cases` on a value whose indices are terms generalizes them with homogeneous equations and solves each case's equations by substitution, injection, conflict and deletion, refusing heterogeneous ones by name; `calc [R₁ := p₁, …]` chains equations, a step proved by `_` left as a goal; `cc` closes an equation the hypotheses entail by congruence (union-find with a proof forest, applications read curried), its proof built from symmetry, transitivity and congruence; `decide` closes a proposition whose `Decidable` instance the kernel computes to `isTrue`, through the proved `of_decide_eq_true`; `simp [l₁, …]` rewrites the goal left to right by each equation (a hypothesis, a lemma or a term, its variables found by first-order matching, the context's `@[simp]` lemmas when none is named) until none applies outside a binder, then closes it by `rfl` when its sides agree, each rewrite a transport citing its lemma, and refuses a run that rewrites nothing or does not stop after `SIMP_STEPS`. A goal's hypotheses print by name in its messages (`interface::print_term_in`). A goal reads its target by conversion only (β, ι on a constructor, K on a proof of an equation whose sides convert).
- **`StandardLibrary::context()`: the standard library, registered once per process.** Borrowed for questions, cloned for a context of one's own (copy-on-write, about a microsecond, against 0.3 s optimized and seconds in a debug build to register a thousand checked declarations and their checked equation lemmas). `interface::standard_context` is that clone, and `certificate::recheck`, `Certificate::axioms_used` and the theorem and environment certificates take their trusted base from it instead of registering the prelude per call.
- **A Lean import's context replays into the core whole.** In `Theory::Logos` the core names Lean content's primitives as the Lean importer spells them in a LOGOS context (`WellKnown::logos`: the `Nat` operations, `Bool`, `Char`, `String`, `List` and the elaborator's markers), checks each by the primitive's equations as Lean's theory does, and computes the validated ones natively on literals; a definition that fails the check is an ordinary one, computed by unfolding and never refused (`dag::primitive::check_primitive_def`), and LOGOS's `true` is a `true` to the `decide` fast path (`WellKnown::logos_true`). Beside them the core computes every program the `Term` kernel's evaluator certifies by its recurrence (an arithmetic operation, a `Nat` order or equality, a division program on a pair such as Lean 4.14's well-founded `Nat.div._unary` and `Nat.modCore._unary`) through that same certificate, reading the operands itself, in weak-head reduction and in lazy δ (`Kernel::reduce_certified_program`); a kernel that follows a later context reads the certificates again. Structure η reads a structure's projections, so the replay order (`dag::logos_env`) puts a declaration that names a structure's constructor after the structure's projections, and a `match` read only to infer its type takes it from its motive. Every Lean original of the `lean_scale` fixtures replays with no refusal; the Omega originals' context had 144, and Lean's division at 2^128 declined at the depth limit.
- **`Int` is Lean's two-constructor inductive, and its sixteen public laws are theorems.** `Int` has the constructors `Int_ofNat | Int_negSucc` in Lean's order, and `add`, `sub`, `mul`, `div`, `mod` and `le` are checked definitions over them (`Int_add`, `Int_sub`, `Int_mul`, `Int_div`, `Int_mod`, `Int_le`), bottoming out in checked `Nat` arithmetic (`Nat_mul`, `Nat_pow`, `Nat_div`, `Nat_mod`). `add_zero`, `mul_zero`, `add_comm`, `mul_one`, `mul_comm`, `mul_assoc`, `add_assoc`, `mul_distrib_add`, `sub_elim`, `le_refl`, `le_trans`, `le_total`, `lt_add1_le`, `le_add_mono`, `le_sub` and `le_mul_nonneg` are proof terms both kernels check with empty axiom closures — the fifteen that were axioms in 0.10.1 keep their statements, and `sub_elim` is new; `lt`, `ge` and `gt` are Lean's bodies over `le`, `lt_succ_le` is `λa b h. h`, and its converse `le_succ_lt` is new. `Literal::Int` and `Literal::BigInt` are definitionally equal to their canonical constructor terms (`int_inductive::canonical_int`) in both kernels and in the `native_decide` evaluator, so an integer literal can be matched on while arithmetic on literals stays compact; the literal accelerations fire only while every dependency of the public operation is the checked one. `int_inductive` exposes the construction (`register_inductive_int`, `register_int_constructors`, `register_int_arithmetic`, `register_nat_arithmetic`, `supports_integer_polynomial_operations`). Locked by `int_prelude_bridge`, `native_integer_bridge`, `derived_integer_ring_laws`, `derived_integer_order` and `tcb_ledger_lock`.
- **The prelude carries Lean's foundations and core library, defined rather than assumed.** `propext` and `Classical_choice` are the two new axioms, the ones Lean assumes; `funext` (from `Quot_sound` and η), `Classical_em` (Diaconescu), `Classical_propDecidable`, `Classical_indefiniteDescription`, `Classical_choose`, `Classical_choose_spec`, `Classical_axiomOfChoice` and `dne` are checked definitions. New: `HEq` with `heq_of_eq`, `cast`, `cast_refl` and `eq_of_heq`; `Setoid` and `Quotient` with `Quotient_mk`/`_sound`/`_lift`/`_ind`/`_rec`; `Option`, `Prod`, `Sum`, `Sigma`, `Subtype`, `Fin`, `List`, `Array`, `UInt8`…`UInt64`/`USize`, `Char` (a Unicode scalar value over `UInt32`), `String` over `List Char`, `Iff`, `Subsingleton`, `Squash`, `Inhabited`, `Nonempty`, `OfNat` numeral dictionaries and `Decidable` instances, all `Type 0` families with ι-reducing eliminators. `Text` computes: `Text_append`, `Text_beq`, `Text_isPrefixOf` and `Text_length` (characters, as Lean's `String.length`) reduce in the kernel and in the `native_decide` evaluator. Locked by `prelude_types_extra`, `P_prelude_extra` and `ofnat_elaboration`.
- **`Quot_rec` is Lean's definition, not an assumption.** `recursor::derive_quot_rec` builds it as Lean's `Init/Core.lean` does (`Quot_lift` into the new `PSigma`, `Quot_ind`, a transport) and registers it through the checked gateway at its unchanged statement; `#print axioms Quot_rec` is `Quot_sound`, read through the body, and `Quot_lift`'s target is `Sort v`. Locked by `quot_rec_definition_lock`.
- **A trusted-base ledger.** `crates/logicaffeine_kernel/TCB.md` argues every assumption `StandardLibrary::register` installs, and `tcb_ledger_lock` enumerates the live `Context` against it by class (`Primitive`, `Definable`, `Reflection`, `DomainSpecific`). The `Definable` count is a downward ratchet, and every constant Lean proves (`funext`, `dne`, the classical layer, the `Int` operations and laws) must stay a definition.

Locked by `axiom_footprint_complete` and `polymorphic_axiom_audit`.

The `recheck` example re-checks any certificate and, with `--package <dir>`, replays a Lean → LOGOS package (exit 0 verified, 1 rejected, 2 single-checked, 64 usage). Locked by `original_unsafe_declaration_refusal`, `lean_import_source_retention` and `lean_arena_runtime_safety`.

### Breaking changes

- **Certificates from v0.10.1 no longer re-check.** `certificate::PRELUDE_VERSION` moved with the prelude; a v0.10.1 certificate is refused (`incompatible_prelude` via `read_certificate`, `CertificationError` via `recheck`). Migration: re-mint with `Certificate::new` against the current prelude. Certificates with unknown JSON fields are also refused (`deny_unknown_fields`).
- **`div`/`mod` semantics.** Euclidean and total: `div (-7) 3 = -3` (was `-2`), `mod (-7) 3 = 2` (was `-1`), `div x 0 = 0`, `mod x 0 = x` (were stuck). Migration: a proof that closed a negative-operand goal by `refl`/computation restates the value; a proof that relied on `div x 0` not reducing now sees `0`.
- **`add_definition` checks its body.** An ill-typed body is refused (listed in `Context::refused_declarations()`), and a body mentioning a not-yet-declared global is a pending obligation invisible to `get_global`/reduction until the global exists. Migration: register in dependency order, or call `Context::declare` to get the `KernelError`, and inspect `pending_obligations()`.
- **Redeclaration under dependents is refused.** `add_definition`/`add_declaration`/`add_constructor`/`add_inductive` on a name something outside its declaration unit depends on (including names the prelude now defines — `Option`, `Prod`, `PSigma`, `List`, `Array`, `String`, `Char`, `Fin`, `HEq`, `Setoid`, `Quotient`, …) records `KernelError::StableMeaningViolation` instead of replacing it. Migration: declare under a new name; an identical redeclaration is still accepted.
- **`Prop : Type 0`.** `infer_type(&ctx, &Term::Sort(Universe::Prop))` and `Universe::Prop.succ()` return `Type 0` (was `Type 1`). By cumulativity everything that typed before still types. Migration: code that compares the inferred sort structurally expects `Type 0`.
- **Instance resolution order.** Higher priority first, ties to the later declaration (was: first registered). Two overlapping instances at default priority now resolve to the later one. Migration: give the intended one a higher priority with `add_instance_with_priority`.
- **Pub enums gained variants (exhaustive matches break).** `Term::Annotated`, `KernelError::{InvalidDeclaration, StableMeaningViolation, IndependentRecheck}`, `elaborate::ParamKind::StrictImplicit`, `interface::Command` (`Theorem`, `Opaque`, `Axiom`, `InductiveBlock`, `Quotient`, `Structure`, `Universes`, `PrintAxioms`, `Protected`, `Open`, `OpenIn`, `Export`, `Surface`, `Comment`), `interface::ParseError` (`AmbiguousName`, `UnbalancedDocument`, `UnknownNamespace`, `TrailingInput`, `MacroDepth`, …); `Command::Definition` has a new `proof_goal: Option<Term>` field (`None` for ordinary definitions). Migration: add arms for the new variants (or a wildcard) and `proof_goal: None` where a `Command::Definition` is constructed.
- **Re-checker error payloads.** `ReCheckError::Unsupported(String)` → `Unsupported(Incomplete)`, `DoubleCheck::MainOnlyReCheckerIncomplete(String)` → `(Incomplete)`. Migration: read `incomplete.message()` / `incomplete.kind()`; `ReCheckError::incomplete()` returns it.
- **Parsers refuse trailing input.** `TermParser::parse`, `parse_command` and `Repl::execute` return `ParseError::TrailingInput` where v0.10.1 silently discarded the rest. Migration: one command per `execute`, or `Repl::execute_document` for a multi-command text.
- **Literate tactic theorems must conclude their goal.** A `## Theorem … Proof: <tactic>.` whose tactic fails is now an error rather than a registered (false) theorem. Migration: fix the proof; the document stops at the first block that does not check.
- **`Literal` equality on `Float`.** `Literal::Float(0.0) != Literal::Float(-0.0)` and `NaN == NaN` (same payload); `Literal` now implements `Eq`. Migration: code that relied on IEEE `==` between literals compares the `f64` values itself.
- **Features/deps.** The `serde` feature now also pulls `serde_json` into the library; `rustc-hash` and `smallvec` are unconditional dependencies. Migration: none in code; dependency audits list the two crates.
- **New globals per definition.** Every checked `declare`/`add_definition` also registers `f_eq_def`/`f_eq_1…` when `Eq` is present, so a later user declaration of one of those names is a redeclaration (and refused if anything depends on it). Migration: choose another name for a user lemma, or cite the generated `f_eq_*` directly.

- **A literal reads only as the constructors it names.** `0` is `Zero` while `Zero : Nat` is a constructor of `Nat`, and `n + 1` is `Succ n` while `Succ : Nat → Nat` is too (`int_inductive::reads_nat_literal`); literal arithmetic still needs `Nat` to be exactly those two. `Context::canonical_numerals` decides all three once per registry generation, through the attestation cache the arithmetic and reflection attestations share (`Context::attested`), and the kernel's two copies of the canonical-`Nat` test now read it. - **A bare reference carries its level into the declaration around it.** Anywhere but an application's head, a bare reference to a universe-polymorphic declaration stands at that declaration's own levels, and a stored term now writes it so (`Context::stored_term`, `term::bare_references_at_own_levels`, at every door that stores a type, body, arity or constructor). A definition with no stated telescope binds the levels of its stored type and then those only its body mentions (`term::definition_telescope`); a stated telescope must bind them all. Both kernels' conversion equates the bare reference with exactly that instance, and never compares a bare head with an explicit one by congruence (a bare head is the instance its arguments solve). Left implicit, `P2 : Sort u := B2` over `B2 : Sort u` was checked with its own `u` and `B2`'s identified and used apart: `P2.{0}` was a proposition holding `B2`'s two constructors and `B2_rec.{1}` eliminated `B2` into data, which together proved `False`. Rule 1's level collection walks a stack of its own, so a door reads a term's levels before its depth limit refuses it. The core's candidates are the stored terms under the door's telescope (`dag::logos_env::{candidate_definition, candidate_axiom, candidate_block}`, now public), and an implicitly polymorphic family's auxiliaries are derived at the levels they are registered at, so Lean's `PUnit_below` is admitted by both kernels.

- **A family that may be a proposition does not eliminate into data.** `match` checked the large-elimination restriction only against a literal `Prop`, so a universe-polymorphic `Two.{u} : Sort u` with two constructors eliminated into `Nat` while `u` was abstract; at `u := 0` proof irrelevance equated `t1.{0}` and `t2.{0}`, and `Eq Nat Zero (Succ Zero)` was a checked definition. The restriction now holds at every instance of the family's universe levels: a family whose level may be `Prop` eliminates into a larger sort only when it is a subsingleton or the result's level is at most its own (`Sort u` into `Sort u` stands). Both kernels, the plain and the indexed `match` (`check_elimination`, `recheck`'s rule).
- **A declared type is checked to be a type.** `Context::declare` checked a body against its declared type but never the type itself, and `Context::add_declaration` registered an axiom at any term, so an ill-typed declared type that reduces to the body's (`(λ(x : Nat). λ(y : Bool). Nat) Zero Zero`) and an axiom at `Zero` were registered. Both are refused now (the axiom's refusal recorded in `refused_declarations`), and a declared type that names a constant declared later is owed as a pending obligation, as a body is. Registering the standard library now also types its generated equation lemmas' statements: 5.78 G instructions instead of 4.44 G (optimized), paid once per process through `StandardLibrary::context`.
- **Unification runs on a stack sized for what it compares.** `elaborate::unify_in` normalizes both sides and then walks the normal forms recursively, on the stack the caller sized for the written terms; a statement over literal arithmetic the positive check declines (`Eq Nat (double 9223372036854775808) 18446744073709551616`) normalizes to a deep partial term, and in a debug build the walk overflowed a 2 MiB test thread. The walk now continues on a stack sized for the normal forms' depth (`term_store::grow_stack_for_depth`), and past the kernel's depth door it is a recorded resource stop.
- **A universe level is never `SProp`.** `SProp` is a sort and not a level, yet `resolve_const_levels` accepted `Two.{SProp}`, and the level solvers (`unify_levels`, the elaborator's `solve_unwritten_levels`) solved `?u := SProp` from an argument in `SProp`, which reopened the same `0 = 1` through `SProp`'s irrelevance. - **The guard's refutation refinement requires a closed decision.** The refinement drops a refuted nullary constructor `C` from the subterm meet of an `isFalse` branch because a kernel-checked decision procedure, closed at `x ↝ C`, cannot reduce to a closed proof of `¬(C = C)`. A procedure with a second open argument could: `dz n e := isFalse (λh. e)` over a hypothesis `e : False` answers `isFalse` at `Zero` under `e`'s binder, so the guard admitted `spinz`, whose `λ(e : False). spinz Zero e` reduces forever. A refinement on `x` is now read only when `x` is the discriminant's only free variable; the `decreasing_by` shape over `decEqNat n Zero` is unchanged. Locked by `kernel_paradox_corpus`.
- **A value-engine probe's budget bounds its work.** The same-head argument probe (`Kernel::probe_steps`) was charged per conversion step only, while one step's lazy-δ loop unfolded without limit; on the Lean Kernel Arena's `navier-stokes-euler`, 3,440 abandoned probes unfolded 84 million times and `EulerSobolevBaseCommutator.baseCommutator_bound` cost 188 G instructions against the leading checker's 0.01 G. Every δ-unfolding step inside a probe now spends the budget too: the test goes from 327.1 G to 180.8 G instructions (mathgraph: 270.6 G); Mathlib, init, std, cslib, cedar and con-leche move by under 0.1%. Locked by `dag_sem_probe::a_probe_spends_its_budget_on_unfolding_too`.
- **A deep import lost its `let`s.** A checked closed `let` in a declaration past the sharing threshold was published with its value copied into every use; it is now kept as a `let` unless the declaration is too deep for the depth door or the value is shared through δ. Locked by `let_sharing`.
- **A package with a large shared construction ran out of work allowance.** The bounded reference projection charged every node it extracted the payload of the whole interned tree it came from, so one large intern made each later extraction cost thousands of times its size, and a Lean package such as `nested_function_field`'s `TFn.swap` could not be built. Each node is now charged its own payload. Locked by `recursor::bounded::accounting_controls` and `nested_function_field`.
- **A raw `Context::add_definition` could mint a closed proof of `False`.** It inserted the body unchecked, so `evil : False := Zero` put a `False` inhabitant in reach of everything registered after it; the body is now checked and an ill-typed one is refused. Locked by `registration_soundness`.
- **Redefinition under a dependent proved `False` with both kernels agreeing.** Redefining a definition a theorem was proved about, adding a constructor after exhaustive elimination, or registering a constructor over a definition's name left the dependent certified for a statement it no longer stated; all three are refused. Locked by `stable_meaning`.
- **A definitional alias walked around strict positivity.** `Definition Negate := Bad -> False` followed by `cons : Negate -> Bad` passed the syntactic check and inhabited `False`; positivity now unfolds references before deciding. Locked by `constructor_blind_positivity`.
- **A failed literate tactic proof was accepted.** `## Theorem … Proof: <tactic>.` type-checked the tactic's error derivation; it must now conclude exactly its goal, and a document stops at the first false block. Locked by `literate_proof_soundness` and `vernacular_extra`.
- **The term parser discarded trailing input.** `Check Nat -> Nat garbage` checked `Nat -> Nat`; trailing input is now `ParseError::TrailingInput`. Locked by `term_parser_total_lock`.
- **`Float` literal equality was IEEE `==`.** Conversion was not reflexive at `NaN` and identified `0.0` with `-0.0`; literals now compare by bit pattern.
- **Deep terms aborted the process.** A term past the native stack killed the checker with a stack overflow; checking runs on sized stacks, past `MAX_TERM_DEPTH` is a refusal, and printing a deep term no longer recurses. Locked by `W_perf_extra` and `term_display_depth`.
- **`simp` folded `div`/`mod` by truncation and stopped silently at fuel.** It now folds with the kernel's Euclidean convention and fails a goal it could not finish simplifying.

# Changelog

All notable changes to this crate will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed
- The web bundle builds for size (`[profile.wasm-release]` opt-level `s`): at opt-level 3 the main wasm was 27.4 MiB, over Cloudflare Pages' 25 MiB per-file limit, and the deploy failed at the upload; at `s` it is 20.8 MiB, inside the `[web]` budget. The in-browser interpreter is built for size with it.

### Fixed

- The prebuilt previews of the shipped Web pages carry the browser runtime whose `read_reals` takes the path the module passes it, as `web_previews_lock` holds them to the compiler.
- The native `server` feature turns on `logicaffeine-lsp/server`, so the server side links one build of the language server. Locked by `feature_forwarding_lock`.
- The landing page cites `lean_arena_big_naturals` for the kernel's Lean integers: the suite it cited is absent from a public checkout.
- `public/llms-full.txt` is the concatenation of the guides `llms_lock` holds it to: the logic guide's generic and the imperative guide's `Real` constants.

## [0.11.0] - 2026-11-02

### Fixed

- The Studio's Math and Logic pages. The Context panel's inductive types and definitions keep one order across Executes (every fresh kernel starts from one cached standard library; `math_context_tests`), and the panel is built once per run instead of on every render. The purple "Working…" button that flashed beside Execute and Compile is gone. A failure nobody planned for — a panic, or the stack running out on a deeply nested term or tactic script — no longer leaves the page dead: `ui::fault::contain` catches the wasm trap at a JavaScript boundary, puts the shadow-stack pointer back (`build.rs` exports `__stack_pointer`), and the Studio shows an orange note just left of the buttons, with the full message in its tooltip. Compile output past 65,535 tokens no longer crashes dioxus's DOM patcher: `CodeEditor` and `CodeView` draw tokens in runs of 4,096. Locked by `src/ui/fault.rs` tests, `tests/fault_hook_chain.rs`, `tests/wasm_fault_boundary.rs`, `tests/code_view_channel_lock.rs` and seven `scripts/web/test-studio-e2e.mjs` scenarios.
- Logic answers are graded by reading them. The grader never looked inside parentheses, and LOGOS writes every formula in them, so on the Learn, lesson and review pages and in the Syntax Guide a wrong noun passed (`Dog(x)` where the key said `Bird(x)`), so did an extra predicate, and a correct answer with single parentheses failed against the double-parenthesised key. `grader.rs` now parses the notation LOGOS prints (quantifiers, counting and generalised ones included, modals, operators over formulas such as `HAB(…)`), names each bound variable by its binder so a renamed variable still matches, compares conjuncts in any order and grouping and names in any case, and treats a dictionary category beside its noun (`Animal(x)` beside `Bird(x)`) as optional, so the textbook answer and the formula LOGOS shows both pass. Locked by `grader::tests`, `learn_examples::the_grader_reads_every_answer_key_it_is_given` (every generated key and reading parses, accepts a renamed bound variable and rejects a renamed predicate) and `guide_delight::every_fol_exercise_accepts_what_logos_shows_for_its_sentence`.
- Prose no longer breaks mid-sentence on a phone.

# LGX reference

Generated from the compiler's catalogues by `lgx_reference_lock`; every example below was parsed by the compiler to produce its row. Do not edit this file: run `./scripts/release/lgx/gen-reference.sh`. [Frontend](frontend.md) teaches the same constructs in order, with pages you can run.

## Template tags

What a `View:` holds, one row per construct.

| Template | Meaning |
|---|---|
| `<p class="note">Saved</p>` | An HTML element. It closes with its end tag; a void element (`input`, `br`, `img` …) takes none. |
| `Saved` | Text. A run that is only whitespace and holds a newline is formatting and is dropped; other runs collapse to one space. |
| `{count}` | The value, escaped. |
| `{title \| truncate 20}` | The value through a filter: this hole is `truncate(title, 20)`. Filters apply left to right. |
| `{raw trustedHtml}` | The value inserted as markup, unescaped — only for text already made safe. |
| `{if count is 0:}<p>none</p>{else if count is 1:}<p>one</p>{else:}<p>many</p>{end}` | The first arm whose condition holds; `{else:}` when none does. |
| `{for each todo in todos, keyed by todo's id, at index i:}<li>{i}. {todo's title}</li>{else:}<li>nothing yet</li>{end}` | One body per item; the `{else:}` arm renders when the collection is empty. See Loop bindings. |
| `{inspect found:}{when Some (name):}<p>{name}</p>{when None:}<p>not found</p>{end}` | The arm whose pattern matches the value. |
| `{let left be length of todos}` | A name bound for the rest of the enclosing scope. |
| `{extends Site}` | This view fills the named layout's blocks. It is the first thing in the view, or absent. |
| `{block main:}<p>nothing here yet</p>{end}` | A layout slot, with the content shown when the page fills nothing. |
| `{block main}` | A layout slot a page fills. |
| `{children}` | Where the caller's markup lands inside a component. |
| `<Badge label={title}/>` | A placed component. A capitalised tag is a component; its attributes are its declared props. |
| `{# a note for the reader #}` | A comment; dropped. |

Spellings from other template languages are refused with the LGX spelling, rather than read as a hole naming a variable:

| Written | LGX spelling |
|---|---|
| `elif` | `else if` |
| `elsif` | `else if` |
| `elseif` | `else if` |
| `otherwise` | `else` |
| `endif` | `end` |
| `endfor` | `end` |

## Directives on elements

| Element | Meaning |
|---|---|
| `<button on-click={add}>Add</button>` | On `click`, runs the action `add`. |
| `<button on-click={remove(todo's id)}>Remove</button>` | On `click`, calls `remove(todo's id)`. |
| `<form on-submit.prevent={add}></form>` | On `submit`, runs the action `add`, qualified by `.prevent` (see Event modifiers). |
| `<input on-keydown.enter={add}>` | On `keydown`, runs the action `add`, qualified by `.enter` (see Event modifiers). |
| `<input bind={draft}>` | Two-way binding between the control and the state field `draft`. |
| `<li class:done={todo's done}>{todo's title}</li>` | The class `done` is present while the condition holds. |
| `<a href="/todos/{todo's id}">open</a>` | A computed `href`, escaped. |
| `<img src={avatarUrl} alt="">` | A computed `src`, escaped. |
| `<input type="text">` | A literal `type`. |
| `<input disabled>` | A boolean attribute: `disabled` is on while it is present. |

## Event modifiers

An `on-<event>` directive takes qualifiers after dots. Every tier reads them through one catalogue; a word it does not know is a compile error.

Behaviour — how the event is treated, on any event:

| Qualifier | Meaning | Browser build |
|---|---|---|
| `.prevent` | The browser's default action (a form posting, a link following) does not run. | yes |
| `.stop` | The event does not propagate to the element's ancestors. | yes |
| `.once` | The listener answers the first event and is then removed. | yes |
| `.capture` | The listener runs in the capture phase, before the target's own listeners. | yes |
| `.passive` | The listener promises not to cancel the default action. | yes |

Keys — one per handler, on `on-keydown`, `on-keyup`, `on-keypress` only. The handler answers when the browser's `KeyboardEvent.key` is the value shown, compared without case.

| Qualifier | `KeyboardEvent.key` | Browser build |
|---|---|---|
| `.enter` | `"Enter"` | yes |
| `.escape` | `"Escape"` | yes |
| `.space` | `" "` | yes |
| `.tab` | `"Tab"` | yes |
| `.backspace` | `"Backspace"` | yes |
| `.delete` | `"Delete"` | yes |
| `.arrowup` | `"ArrowUp"` | yes |
| `.arrowdown` | `"ArrowDown"` | yes |
| `.arrowleft` | `"ArrowLeft"` | yes |
| `.arrowright` | `"ArrowRight"` | yes |
| `.home` | `"Home"` | yes |
| `.end` | `"End"` | yes |
| `.pageup` | `"PageUp"` | yes |
| `.pagedown` | `"PageDown"` | yes |
| any single printable character, such as `.a` | that character | yes |

System keys — named by the catalogue and refused on every tier:

| Qualifier | Verdict |
|---|---|
| `.ctrl` | A system-key qualifier (`.ctrl`) is refused: no tier delivers modifier-key state to a handler. |
| `.alt` | A system-key qualifier (`.alt`) is refused: no tier delivers modifier-key state to a handler. |
| `.shift` | A system-key qualifier (`.shift`) is refused: no tier delivers modifier-key state to a handler. |
| `.meta` | A system-key qualifier (`.meta`) is refused: no tier delivers modifier-key state to a handler. |

The refusals:

- A word the catalogue does not know is refused, naming the nearest one: `.stpo` → `.stop`.
- A key qualifier on an event that carries no key is refused: `.enter` on `click`. Keys belong on `on-keydown`, `on-keyup`, `on-keypress`.
- One handler answers one key: `.enter` with `.escape` is refused; write a handler per key.
- A system-key qualifier (`.ctrl`) is refused: no tier delivers modifier-key state to a handler.
- `.prevent` and `.passive` on one handler are refused: a passive listener ignores `.prevent`, so a browser would run the default action anyway. Write one or the other.

## Triggers

A sentence in a component's `Actions:` that runs its indented body when something happens. The form is how a compiler message quotes the sentence.

| Sentence | Form | Runs |
|---|---|---|
| `When the page loads:` | `When the page loads:` | Once, when the page mounts, before its first paint. |
| `When this component appears:` | `When this component appears:` | When this component enters the page. |
| `When this component disappears:` | `When this component disappears:` | When this component leaves the page. |
| `When "#save" is clicked:` | `When "…" is …:` | On `click` at that element. |
| `When the user types in "#draft":` | `When "…" is …:` | On `input` at that element. |
| `When the user presses Enter in "#draft":` | `When "…" is …:` | On `keydown` at that element, for the `Enter` key. |
| `When the user presses Escape:` | `When the user presses …:` | On the `Escape` key, anywhere on the page. |
| `When n changes:` | `When … changes:` | After a turn changes this component's `n`. |
| `When Session's name changes:` | `When <Store>'s … changes:` | After a turn changes the store's field `Session's name`, in every component that uses the store. |
| `Every 60 seconds:` | `Every … seconds:` | Repeatedly, once per period. |
| `Every 60 seconds as tick:` | `Every … seconds:` | Repeatedly, once per period; named, so `Stop the timer tick.` cancels it. |
| `After 5 seconds:` | `After … seconds:` | Once, after the delay. |
| `After 5 seconds as reminder:` | `After … seconds:` | Once, after the delay; named, so `Stop the timer reminder.` cancels it before it fires. |
| `When a message arrives on "news" (body: Text):` | `When a message arrives on …:` | On each message published on the topic; `body` binds its payload as `Text`. |
| `When an action fails (why: Text):` | `When an action fails …:` | After a turn fails and is rolled back; `why` binds the failure message. |
| `When a fetch fails (url: Text) and (why: Text):` | `When a fetch fails …:` | After any request fails; `url` binds its URL and `why` the reason. |
| `When the route changes:` | `When the route changes:` | After every navigation. |
| `When the app goes offline:` | `When the app goes offline:` | When the network goes. |
| `When the app comes back online:` | `When the app comes back online:` | When the network comes back. |
| `When the window resizes:` | `When the window resizes:` | When the window is resized. |
| `When the user scrolls to the bottom:` | `When the user scrolls to the bottom …:` | When the page is scrolled to its bottom. |
| `When the user scrolls to the bottom of "#list":` | `When the user scrolls to the bottom …:` | When that element is scrolled to its bottom. |
| `When a file is dropped on "#zone" (file: File):` | `When a file is dropped on …:` | When a file is dropped on that element; `file: File` binds the whole `File` record. |
| `When a file is dropped on "#zone" (name: Text):` | `When a file is dropped on …:` | When a file is dropped on that element; `name: Text` binds the file's name. |

`When "#sel" is <word>:` takes these words:

| Word | DOM event |
|---|---|
| `clicked` | `click` |
| `submitted` | `submit` |
| `focused` | `focus` |
| `blurred` | `blur` |
| `hovered` | `mouseover` |
| `changed` | `change` |
| `typed` | `input` |
| `keyed` | `keyup` |

| `Blur "#draft".` | `Actions:` and `## Test` | Takes focus off the element and raises `blur`. |
| `Hover "#draft".` | `Actions:` and `## Test` | Raises `mouseover` on the element. |
| `Navigate to "/todos".` | `Actions:` and `## Test` | Adds a history entry and routes to it. |
| `Reload the page.` | `Actions:` and `## Test` | Tears down every instance, listener and mounted root; browser storage stays. |
| `Scroll to "#draft".` | `Actions:` | Scrolls the element into view. |

| `Remove class "shake" from "#draft".` | `Actions:` | Removes one class word from the element. |
| `Select the text in "#draft".` | `Actions:` | Selects the text in the element. |
| `Copy draft to the clipboard.` | `Actions:` | Writes the text to the clipboard. |
| `Download draft as "notes.txt".` | `Actions:` | Hands the visitor the bytes as a file with that name. |
| `Replace the URL with "/todos?page=2".` | `Actions:` | Replaces the current history entry; no new entry. |
| `Go back.` | `Actions:` | Goes one history entry back. |
| `Set the title to "Todos".` | `Actions:` | Sets the document title. |
| `Save draft as "draft".` | `Actions:` | Writes the value to browser storage under the key. |

| `Notify "Saved.".` | `Actions:` | Shows a notification. |

| `Press "Enter" in "#draft".` | `## Test` | Presses the key at the element. |
| `Press "Escape".` | `## Test` | Presses the key at the element. |
| `Raise "offline".` | `## Test` | Causes an event that happens to the page, not to an element (`offline`, `online`, `resize`). |
| `Mount Badge.` | `## Test` | Creates the component's root instance and renders it. |

## Page queries

What a `## Test` asks the page, inside `Expect that …`.

| Query | Noun | Asks |
|---|---|---|
| `the text of "#n"` | `text` | The element's text content, its descendants' included. |
| `the count of ".row"` | `count` | How many elements match. |
| `the value of "#draft"` | `value` | An input's current value. |
| `"#n" is visible` | `visible` | Whether anything matches. |
| `"#n" is hidden` | `hidden` | Whether nothing matches — the complement of `visible`. |
| `"#save" is disabled` | `disabled` | Whether the match carries `disabled`. |
| `"#done" is checked` | `checked` | A checkbox's or radio's live checked state. |
| `"#draft" is focused` | `focused` | Whether focus is on the match. |
| `the journal` | `journal` | The actions that ran, in order, as a `Seq of Text`. |
| `the journal shows increment then decrement` | `journal ordering` | Whether the first action ran and the second ran after it, not necessarily next. |
| `the title` | `title` | The document title. |
| `the URL` | `URL` | The current path. |

## Loop bindings

`{for each todo in todos, keyed by todo's id, at index i:}<li>{i}. {todo's title}</li>{else:}<li>nothing yet</li>{end}`

| Binding | Value |
|---|---|
| `todo` | Each item of the collection in turn. |
| `todo's id` | The row's identity: a row whose key survives a re-render keeps its element and its state. |
| `i` | The item's position. The first item is 1, the position `item i of todos` reads. |
| `{else:}` | Renders instead when the collection is empty. |

## Filters

A filter is any function whose first parameter takes the hole's value: `{x | f a b}` is `f(x, a, b)`. The list-view filters come from `ui.lg`:

| Filter | Function | Answers |
|---|---|---|
| `{total \| pageCount perPage}` | `pageCount(total: Int, perPage: Int) -> Int` | How many pages `total` items make at `perPage` each. |
| `{page \| clampPage total perPage}` | `clampPage(page: Int, total: Int, perPage: Int) -> Int` | `page` brought inside `1` to `pageCount(total, perPage)`. |
| `{page \| pageStart perPage}` | `pageStart(page: Int, perPage: Int) -> Int` | The 1-based index of the first item on `page`. |
| `{page \| pageEnd perPage total}` | `pageEnd(page: Int, perPage: Int, total: Int) -> Int` | The 1-based index of the last item on `page`, never past `total`. |
| `{t \| truncate n}` | `truncate(t: Text, n: Int) -> Text` | `t` cut to at most `n` characters, marked with `…` when anything was removed. |
| `{n \| plural one many}` | `plural(n: Int, one: Text, many: Text) -> Text` | `n` with the word that agrees with it: `1 item`, `2 items`, `0 items`. |
| `{name \| initials}` | `initials(name: Text) -> Text` | The first letter of each word of `name`, run together: `Ada Lovelace` is `AL`. |
